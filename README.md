## Getting Started


1. Click **Use this template -> Create a new repository**. 
2.	On the next screen, select your username as the Owner and enter a meaningful name for the repository (e.g. cm2115-assessment).
3.	Select **Private** as the visibility.
4.	Click **Create repository**
5.	When the repo is created, click **Settings**, then **Collaborators**, then **Add people**. Add **marksnaith** – this is so your GitHub usage can be assessed during grading. 
6. You can now clone the repo to your local machine and start development
